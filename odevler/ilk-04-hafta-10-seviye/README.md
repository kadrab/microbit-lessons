# Weeks 1–4 review homework — ten levels

Language: English | [Türkçe](README.tr.md)

This cumulative homework pack combines sequencing, `forever`, `if/else`, and fixed-count `for` repetition without introducing a new concept. It reviews the first four weeks; it is **not Week 5**.

All required pieces are supplied in the first nine levels, but their placement is deliberately incorrect. Level 10 contains only the task comment, so children choose and connect the blocks themselves. The regular weekly format of five core activities plus a sixth homework task does not reduce this cumulative pack: it retains all ten levels.

| Level | Activity | Main idea |
|---|---|---|
| 1 | Four-light greeting | Separate repeated actions from the final action |
| 2 | The robot that wakes in the dark | Keep checking an `if/else` condition |
| 3 | Growing heart | Opening, repeated sequence, and ending |
| 4 | Two-part coded message | Run two repeat blocks in sequence |
| 5 | Four check-ins | Read B again on every round |
| 6 | Choose the message packet | Read B once before the selected repeat block |
| 7 | Automatic beacon | Select and repeat a complete packet continuously |
| 8 | Two stations | Combine two different repeated checks and an intermission |
| 9 | Night watch | Combine light selection with repeated button checks |
| 10 | Command centre | Build the complete system independently |

Use a separate MakeCode project for each task. Replace the code in its JavaScript tab with the entire student file, then switch to Blocks. Keep the blank line after the opening task comment so that it becomes an open workspace comment. Student-facing code comments remain in Turkish.

Start with about two levels per 20–30-minute session; harder tasks may need a session of their own. Do not add all ten levels as mandatory work on top of unfinished homework. When children can explain when and how often a decision is checked, a simple counting game is a suitable next step toward variables.

The local logic checker is `verify_logic.cjs`; it prints its results to standard output. See the instructor guide for previous validation and its limits. No physical micro:bit test has been performed.
