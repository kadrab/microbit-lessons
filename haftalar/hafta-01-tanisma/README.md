# Week 1 — Meet the micro:bit

[Türkçe](README.tr.md) · [Instructor guide](INSTRUCTOR.md)

No standalone source file from the original introductory session was found. This outline reconstructs the intended introduction to the LED display and A/B buttons from the earlier lesson plan. It is not an exact record of the delivered session or a test report. This week currently has no prepared student programs, solutions, or downloadable packages.

The goal is to connect a button event with a visible output: “When I do this, what does the micro:bit do?” Variables, conditions, and repeat counts are not needed yet.

## A 20–30 minute session

| Time | Children's activity | Suggested explanation |
|---|---|---|
| 0–5 min | Find the LED display and A/B buttons. Choose two faces to display. | “We will choose this little robot's faces. Each button will give it a different job.” |
| 5–12 min | Build a program together that shows the first face when A is pressed. | “First we say when the program should run. Inside that block, we put the job it should do.” |
| 12–20 min | Swap roles and make B show the second face. | “A and B are two different starting points. The button you press chooses the job.” |
| 20–25 min | Predict the result of A, B, B, A, then test it. | “Say which face you expect before pressing the button. Then check your prediction.” |
| Optional extra 5 min | Swap the faces and repeat the same button sequence. | “We changed the robot's instructions. What will the same buttons show now?” |

One child places the blocks while the other predicts and tests. Then swap roles so both children use the computer and explain the result.

## What they should be able to explain

- “Which block runs when I press A?”
- “Where should I go to change the face shown by B?”
- “What changes if I move an icon into the other button event?”

Finishing quickly is less important than both children being able to predict and explain. The next step is [Week 2: conditions using prepared blocks](../hafta-02-kosullara-giris/README.md).
